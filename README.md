# Paprika vectorielle

![Aperçu](preview.jpg)

Reproduction vectorielle de l'affiche de **Paprika** (Satoshi Kon, 2006), redessinée avec [Inkscape](https://inkscape.org) sur l'image originale.

L'objectif était d'obtenir une version adaptée à une impression grand format (>100cm).
L'affiche n'est pas vectorisée en entier : le travail s'arrête aux limites du cadre d'impression.

## Contenu

| Fichier | Description |
|---|---|
| `paprika.svg` | Source Inkscape, avec ses calques (`Face`, `Hairs`, `Shadows`, `Mess`…) |
| `canvas_impression.svg` | Gabarit du format d'impression (110 × 66 cm) |

## Contribuer

Pour compléter la vectorisation, ouvrez `paprika.svg` dans Inkscape (1.0 ou plus récent). Le calque `Original`, masqué par défaut, sert de modèle à décalquer. Les pull requests sont les bienvenues.
